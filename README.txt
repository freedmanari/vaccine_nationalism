
GENERAL INFORMATION

Data
- sim_results/*, gives the output from simulations taking longer than ~10 minutes to run, these numpy data files can be loaded in to vaccine_nationalism.ipynb to skip long computations if desired

Figures
- figures/*, final pdfs of all figures

Scripts
- vaccine_nationalism.ipynb, main script, can run all simulations and make all figures
- get_sim_results.py, optional script to run long computations with parallelization on HPC, saves about 30-40 hours of computation
